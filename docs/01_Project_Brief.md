# 01 项目概述

> 状态：初始草案，待细化与确认。

## 产品定位
基于动态任务规划与证据校验的笔记本电脑选购 Agent。

## 用户问题
用户难以将预算、用途和便携等需求转化为可验证的商品选择，也难以理解配置之间的取舍。

## MVP 范围
- 有限商品目录、有限用途适配规则、单 Agent。
- 自然语言需求、必要澄清、商品检索、适配核验。
- 推荐 2～3 款候选；不足时如实展示，不凑数。
- 单款追问、候选比较、条件变更、无法推荐时的解释。
- 可查看脱敏后的执行轨迹。

## 非 MVP 范围
全品类、实时电商爬取、支付下单、多 Agent、通用 Harness 平台。

## 价值假设
动态行动选择能在信息缺口不同的场景下，改善可靠性或减少无效交互；需要与固定工作流实测比较。
