# 02 产品需求

> 状态：文档模板，尚未形成完整开发规格。

## 核心用户旅程
输入需求 → Agent 根据状态执行必要行动 → 澄清或展示候选 → 追问、比较或修改条件。
澄清和查询顺序可变，不强制先问完再查询。

## 功能清单
| 功能 | 需要细化的验收点 |
| --- | --- |
| 需求理解 | 预算、用途、硬条件、偏好及未知信息 |
| 必要澄清 | 问题能影响候选或适配结论，避免重复询问 |
| 商品推荐 | 展示依据、取舍、未知项；遵守硬条件 |
| 单款追问 | 使用商品事实和证据回答 |
| 候选比较 | 对齐比较维度，区分未知与不满足 |
| 条件修改 | 更新需求并重新验证受影响结论 |
| 异常反馈 | 区分无匹配、证据不足、工具失败和执行超限 |

## 页面与组件
- 对话输入与消息区。
- 用户条件卡片。
- 商品推荐卡片与对比视图。
- 澄清问题与任务状态提示。
- 演示用执行轨迹面板。
